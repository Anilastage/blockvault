# Deploy BlockVault for Free (no domain, no money)

BlockVault is made of 3 hosted pieces. Two are already live:

| Piece | Status | Hosting |
|---|---|---|
| Smart contract | ✅ Deployed | Sepolia (chain 11155111) |
| MongoDB database | ✅ Live | MongoDB Atlas (free tier) |
| Backend API (Express) | ⬅ Deploy | Render (free) |
| Frontend (React/Vite) | ⬅ Deploy | Vercel (free) |

You get free URLs like `https://blockvault-api.onrender.com` (backend) and
`https://blockvault.vercel.app` (frontend). No domain needed.

---

## 1. Deploy the Backend (Render.com)

1. Go to **https://render.com** → sign up with GitHub.
2. Click **New → Web Service**.
3. **Connect your GitHub repo** (`Anilastage/blockvault`).
4. Render auto-detects `render.yaml`. If it asks manually:
   - **Root Directory:** `backend`
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `node dist/server.js`
5. Render will prompt for the service vars from `render.yaml`. Set these:

   | Env var | Value |
   |---|---|
   | `NODE_ENV` | `production` |
   | `MONGODB_URI` | Your Atlas connection string (from `backend/.env`) |
   | `JWT_SECRET` | auto-generated by Render, or make your own long random string |
   | `CLIENT_URL` | Your Vercel frontend URL, e.g. `https://blockvault.vercel.app` |
   | `BLOCKCHAIN_RPC_URL` | `https://ethereum-sepolia-rpc.publicnode.com` |
   | `CHAIN_ID` | `11155111` |
   | `CONTRACT_ADDRESS` | `0xe68C76d721952aECF9F19A5461adF0BD2b0801D4` |
   | `BLOCKCHAIN_EXPLORER_URL` | `https://sepolia.etherscan.io` |
   | `SMTP_ENABLED` | `true` |
   | `SMTP_HOST` | `smtp.gmail.com` |
   | `SMTP_PORT` | `587` |
   | `SMTP_USER` | your Gmail address (e.g. `you@gmail.com`) |
   | `SMTP_PASS` | a Google **App Password** for that Gmail |
   | `EMAIL_FROM_ADDRESS` | your Gmail address (same as `SMTP_USER`) |
   | `EMAIL_FROM_NAME` | `BlockVault` |

6. Click **Create Web Service**. Wait ~3 min for the first build.
7. **Important:** Render free web services are set to **spin down after 15 min idle**. Go to the service **Settings → Instance → Auto-Deploy / sleeping** and check you're on the free plan. (If you want it to never sleep, that costs ~$7/mo — not required for a demo.)

> ✅ **Email OTP (recommended).** The app sends real verification codes by email.
> To create a Gmail App Password: Google Account → **Security → 2-Step Verification**
> must be ON, then **App passwords** → "App" → other (custom name, e.g. `blockvault`) →
> copy the 16-char password into `SMTP_PASS`. Then real emails go out and the
> on-screen `devCode` disappears automatically.
>
> `SMTP_USER`, `SMTP_PASS` and `EMAIL_FROM_ADDRESS` are marked `sync: false` in
> `render.yaml` — you must fill them in the Render dashboard manually (Environment
> tab → Add Environment Variable). Only push them if you want them public.

## 2. Deploy the Frontend (Vercel)

1. Go to **https://vercel.com** → sign up with GitHub.
2. Click **Add New → Project** → select `blockvault`.
3. Vercel detects Vite + the `frontend/vercel.json` config automatically.
4. Set the environment variable, then click **Deploy**:

   | Env var | Value |
   |---|---|
   | `VITE_API_URL` | `https://<your-api>.onrender.com/api` |

   (The `/api` suffix is required.)

5. After deploy you get `https://blockvault.vercel.app`.

---

## 3. First-use checklist on the live site

- Open the Vercel URL → **Register** the first account (becomes admin).
- **Email verification is mandatory at signup** — enter the code emailed to you
  (or the on-screen `devCode` if SMTP isn't configured yet) before you can log in.
- In **Profile** → connect your MetaMask wallet (must be on Sepolia with a little ETH).
- No MetaMask? A **"MetaMask not detected"** modal appears with install
  instructions for desktop, iPhone and Android when you click *Connect Wallet*.
- Upload a document — it signs a transaction on Sepolia via MetaMask and lands in the Atlas DB.

## 4. Updating after a code change

Both are connected to GitHub:
- Push to `master` → **Vercel auto-redeploys** the frontend.
- Push to `master` → **Render auto-redeploys** the backend (if redeploys are on).

## Troubleshooting

- **Backend returns 401/network errors on the live site** → `CLIENT_URL` on Render must
  exactly match the Vercel URL (no trailing slash), and `VITE_API_URL` must end in `/api`.
- **Registration says "transaction failed"** → your MetaMask wallet needs a little Sepolia
  ETH (claim from a faucet).
- **Downloading files fails on the live site** → Render's free tier has a 50 MB disk; your
  uploaded files are stored there and count toward that limit.
